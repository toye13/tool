USER TOKEN MODE
⚠️ 重要警告（User Token使用時）
・User Tokenでの大量操作はアカウント凍結のリスクが非常に高いです。
・Discordの利用規約（ToS）違反になる可能性があります。
・自己責任で使用してください。バックアップ目的以外での使用は推奨しません。
・可能であればBot Tokenの使用を強くおすすめします。

User Token 設定
自分のDiscordアカウントのUser Token
▾
🔒 トークンはブラウザ上でのみ使用され、外部には送信されません。
User Tokenの取得方法：
1. Discord Web版（discord.com）にログイン
2. F12キー → Application（またはStorage）タブ → Local Storage → https://discord.com
3. token の値をコピー（引用符は不要）
