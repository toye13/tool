Discord Clone Toolサーバー複製ツール v1.0

GitHub Pages対応
⚠️ 注意事項： 本ツールは Discord Bot Token を使用してサーバー構造を複製します。 Botには対象サーバーへの適切な権限が必要です。 Discordの利用規約に従った用途（バックアップ・移行等）にのみご使用ください。 トークンは第三者に共有しないでください。
01
Bot Token 設定
Discord Developer Portal からトークンを取得
▾
🔒 トークンはブラウザ上でのみ使用され、外部サーバーには送信されません。
取得方法：
1. discord.com/developers/applications を開く
2. アプリを選択 → Bot タブ → Reset Token
3. 必要な Intents: GUILDS GUILD_MEMBERS GUILD_MESSAGES
02
コピー元サーバー
複製したいサーバーのIDを入力
▾
サーバーIDの確認方法：
Discord の設定 → 詳細設定 → 開発者モード をON
サーバーアイコンを右クリック → IDをコピー
03
コピー先サーバー
空のサーバーIDまたは新規作成
▾
事前に空のサーバーを作成してBotを招待しておいてください。
Bot招待URL生成：
Developer Portal → OAuth2 → URL Generator
Scopes: bot   Permissions: Administrator（推奨）
04
複製オプション
コピーする要素を選択
▾
レート制限エラーが出る場合は遅延を増やしてください。
05
実行
複製を開始します
▾
⚠️ 実行前に確認： コピー先サーバーの既存チャンネル・ロールは削除される場合があります。 空のサーバーへの複製を推奨します。
